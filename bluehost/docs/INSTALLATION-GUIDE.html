Installation Guide

Deploy the GEEK Enterprise HRIS on standard cPanel shared hosting — from creating the subdomain to first sign-in.

For: Installer / IT Platform: cPanel · PHP 8 · MySQL 8 Time: ~20–30 minutes

This guide installs the HRIS into a subdomain on your hosting account. You'll create a subdomain and a MySQL database, upload and extract the package, point it at the database, seed the first administrator, enable HTTPS, and sign in. No server software needs to be compiled.

Before you start — have these ready

① Access to your hosting cPanel. ② The application package ZIP. ③ A subdomain name you want (e.g. hris.yourdomain.com). ④ Your license key (if your copy requires activation).

Step 1 Subdomain

Create the subdomain

  1. Open Domains → Subdomains.

    In cPanel, find the Domains section and click Subdomains (on some themes it's under Domains → Create a New Domain).

  2. Enter the subdomain.

    Type the prefix, e.g. hris, and choose your domain. cPanel fills a Document Root automatically (e.g. /home/USER/hris.yourdomain.com). Note this path — the package goes here.

  3. Create it.

    Click Create. The subdomain is live within a minute or two.

Step 2 Database

Create the database & user

Use the MySQL Database Wizard (Databases section) — it does all three parts in order.

  1. Create a database.

    Give it a short name, e.g. hris. cPanel prefixes it with your account, so the real name becomes something like youracct_hris — note the full name.

  2. Create a database user.

    Set a username (e.g. hris_admin → real name youracct_hris_admin) and a strong password. Note all three: database name, user, password.

  3. Grant ALL PRIVILEGES.

    On the privileges screen, tick ALL PRIVILEGES and finish. The user now owns the database.

Write these down

You'll paste the database name, user, and password into the configuration file in Step 5. Keep them handy.

Step 3 Files

Upload & extract the package

  1. Open File Manager.

    cPanel → Files → File Manager. Navigate into your subdomain's Document Root from Step 1.

  2. Upload the ZIP.

    Click Upload, choose the package ZIP, and wait for it to reach 100%.

  3. Extract it here.

    Back in File Manager, right-click the ZIP → Extract → extract into the same subdomain folder. You should now see index.html, api/, app/, assets/, and db/.

  4. Delete the ZIP.

    Remove the uploaded ZIP to keep the folder clean.

Files must sit at the root of the subdomain

If extracting created a wrapper folder (e.g. everything inside geek-hris/), move the contents up one level so index.html is directly in the subdomain's Document Root.

Step 4 Schema

Import the database schema

Load the tables into the database you created. Either method works — Terminal is fastest and avoids timeouts.

Option A — Terminal (recommended)

cPanel → Advanced → Terminal, then (replace the names with yours):

cd ~/hris.yourdomain.com mysql -u youracct_hris_admin -p youracct_hris < db/schema.sql

Enter the database password when prompted (nothing shows as you type).

Option B — phpMyAdmin

  1. Open phpMyAdmin

    cPanel → Databases → phpMyAdmin, then select your database on the left.

  2. Import the file

    Import tab → choose db/schema.sql from the package → Go. If it times out on a large import, use Option A instead.

Step 5 Configure

Point the app at your database

  1. Copy the sample config.

    In File Manager, open the app/ folder. Copy settings.sample.php and rename the copy to settings.php.

  2. Edit settings.php.

    Right-click → Edit. Fill in your database name, user, and password from Step 2.

  3. Set a JWT secret.

    Replace the jwt_secret value with a long random string. Generate one in Terminal:

php -r "echo bin2hex(random_bytes(48)).PHP_EOL;"

Paste the output as the jwt_secret. Save the file.

Optional settings

storage_quota_gb — your plan's storage limit, so the dashboard shows real usage. backup_path — a folder for DB backups. Both can be left as-is.

Step 6 Seed

Create the first administrator

This creates the roles, permissions, statutory rules, and your Super Admin login. Run once, in Terminal:

cd ~/hris.yourdomain.com php db/seed.php --minimal

The default login is admin@demo-hris.local / Admin123! — change it immediately after first sign-in. To set your own from the start, run instead:

DEFAULT_ADMIN_EMAIL="you@yourdomain.com" DEFAULT_ADMIN_PASSWORD="A-strong-pass1" php db/seed.php --minimal
Clean up the installer files (optional)

After seeding you can delete the db/ folder (schema + seeders) — the app doesn't need it to run. Keep a copy locally.

Step 7 HTTPS

Turn on HTTPS (SSL)

  1. Run AutoSSL.

    cPanel → Security → SSL/TLS Status. Find your subdomain and click Run AutoSSL. A free certificate is issued in a few minutes.

  2. Confirm it's secure.

    Visit https://hris.yourdomain.com — you should see the sign-in page over a secure (padlock) connection.

Step 8 License

Activate the license

If your copy requires activation, you'll see an amber “not activated” banner after signing in.

  1. Sign in as the administrator.
  2. Open Administration → License.
  3. Paste your key and click Activate.

    The key is issued for this exact domain; once accepted the banner disappears and the app is fully unlocked.

No banner?

Then activation isn't required for this installation — you're ready to go.

Step 9 Go live

First sign-in & setup

  1. Change the admin password.

    My Self-Service → Security.

  2. Brand it.

    Administration → Branding — upload your logo (a wide transparent PNG, about 400×120 px).

  3. Create your organization(s).

    Administration → Organizations → New Organization. Each new org starts with default leave types.

  4. Set up departments & positions.

    Open the org, then Org Setup.

  5. Add people & give them logins.

    Add employees under People, then Administration → Users → Provision Employee Logins to create self-service accounts in bulk.

Hand staff the user guide

The employee guide is built in at https://hris.yourdomain.com/manual.html and via the Help link inside the app.

Troubleshooting

If something isn't right

SymptomFix
"Could not open input file: db/schema.sql"You're not in the subdomain folder. cd into it first (Step 4), or run find ~ -name schema.sql to locate it.
"Access denied for user…"The database name/user/password in app/settings.php don't match Step 2. Re-check the account-prefixed names.
"Table … doesn't exist"The schema import didn't complete (often a phpMyAdmin timeout). Re-run the import via Terminal (Step 4, Option A).
Signed out immediately / at randomThe host stripped the Authorization header. The bundled .htaccess already handles this — make sure it was extracted (enable "show hidden files" in File Manager).
Blank page / 500 errorConfirm PHP 8 is selected (cPanel → MultiPHP Manager) and that settings.php exists with valid values.
Logo upload failsCreate an empty uploads folder in the subdomain root via File Manager, then retry.
